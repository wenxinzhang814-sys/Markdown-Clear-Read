# 清阅 Markdown 阅读器

这是一个轻量 Windows Markdown 阅读器原型，使用系统自带的 HTA 容器和 .NET Framework 启动器运行，不需要安装 Node.js 或启动额外服务。

## 运行

直接双击 `清阅 Markdown.exe` 启动。点击右上角“＋”选择 `.md` 文件，或者把 `.md` 文件拖到清阅窗口中打开；也可以把 `.md` 文件拖到 `清阅 Markdown.exe` 图标上。

双击 `install-association.cmd` 会在当前用户下注册 `.md` 文件关联。设置后，双击任意 Markdown 文件即可打开；不设置文件关联也不影响使用。

请先完整解压下载的 ZIP，把 `清阅 Markdown.exe`、`reader.hta` 和其余运行脚本保存在同一个文件夹。更新时先关闭旧窗口，再使用新下载的整个文件夹。

## 文件打不开时

- 旧版本的“＋”只能选择文件夹，无法加载文件；请重新下载本仓库最新版。
- 新版本支持“＋”、`Ctrl+O` 和拖入窗口。读取失败会显示原因，并保留已打开的文档。
- 若窗口内拖入仍受系统限制，请使用“＋”选择文件，或把文件拖到 `清阅 Markdown.exe` 图标上。
- 拖入窗口时，系统可能只提供文件内容而不提供所在目录；此时文档里的相对路径图片可能无法显示。需要显示这类图片时，请把 `.md` 文件拖到 `清阅 Markdown.exe` 图标上打开。

## 说明

当前版本聚焦快速阅读：标题层级、粗体、斜体、链接、引用、列表、代码块、表格、任务列表和图片均有基础支持；窗口内支持目录、搜索和浅色/深色主题。

## 验证

开发者可以运行 `node --test tests/open-file.test.cjs` 检查打开文件的回归用例。Windows 上运行 `tests/hta-smoke.ps1` 可以验证真实 HTA 宿主中的启动参数、中文路径、连续打开和 FileReader 读取流程；测试只会在 `.work/` 内创建临时文件，不修改系统文件关联。
